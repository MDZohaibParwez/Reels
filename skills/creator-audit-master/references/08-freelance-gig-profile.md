# FREELANCE / GIG / SERVICE PROFILE MASTER (Fiverr, Upwork, tech-services profiles)

## Module 1: Data samjho (3 hisse)
1. Impressions kam -> profile search mein nahi aa rahi (SEO/keyword issue).
2. Impressions zyada, clicks kam -> title, thumbnail ya starting price attractive nahi.
3. Clicks zyada, inquiries kam -> bio/overview, portfolio ya pricing mein trust nahi.

## Module 2: Log profile kyu nahi dekh rahe (5 badi problems)
1. Weak SEO & keywords (generic "Cloud Setup" vs specific "AWS Cloud Migration & Serverless Architecture").
2. Boring thumbnail / profile pic (casual pic, chhota/blurry text).
3. Freshness: purani profile jo update nahi hoti (hypothesis — platform-dependent).
4. Pricing mismatch (bina proof bahut zyada, ya bahut kam = low-quality signal).
5. Low response rate (late replies -> search mein niche).

## Module 3: Edit & improve
Step 1 Title = Service + Benefit/Result. Galat: "I will do AWS cloud setup." Sahi: "I will architect secure AWS cloud infrastructure & reduce server costs by 30%."
Step 2 Overview client-centric: Hook (client ki problem) -> Solution -> Proof (past result) -> CTA ("Message me for a free audit").
Step 3 Portfolio as case studies: Challenge -> Action (tools used) -> Result (metrics).
Step 4 Skills/tags: outdated hatao, current in-demand skills daalo.

## Module 4: Weekly self-audit
- Title top 3 competitors se better/clear?
- Thumbnail/pic high-quality professional?
- Pichle 7 din mein chhota edit kiya (description/tags/price)?
- Bio mein "I" kam, "You/Your business" zyada?
- FAQ section added?
A/B trick: clicks nahi -> 3 din ke liye title + thumbnail change. Phir bhi nahi -> pricing/portfolio check.

## Module 5: Routine
Daily 15 min: analytics (impressions vs clicks), inquiries ka reply 1 ghante mein, network mein 1 relevant post engage.
Weekly 1 hr: keywords update, portfolio mein 1 case study, purane client se review request.

Pro-tip: jargon se mat darao — business value (security, cost-saving, speed) dikhao. "Technical expert" nahi, "business problem solver".
